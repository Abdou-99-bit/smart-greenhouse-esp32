# 🌿 ESP32 Smart Greenhouse & IoT Portfolio

An automated climate management system built using the ESP32 microcontroller, designed to monitor environmental sensors and execute physical automation logic.

## 🛠️ Hardware Components Used
* **Microcontroller:** ESP32 (Wi-Fi & Bluetooth enabled)
* **Sensors:** DHT11/DHT22 (Temperature & Humidity), Soil Moisture Sensor, LDR (Light Dependent Resistor)
* **Actuators:** Relays for Water Pump, Automated Ventilation Fans, and Grow Lights
